Initial 0.1.0 release of @scheman/core — universal schema ingestion and metadata extraction.

Features:
- JSON Schema ingestion with $ref dereferencing
- Zod v3 and v4 schema extraction
- Pluggable extractor registry
- Schema middleware pipeline
- Metadata merge with precedence rules
- Field type detection and metadata mapping
- StandardSchema v1 compatibility
